# Credit_risk_ml
This project is a Streamlit-based credit risk assessment application designed to predict the likelihood of loan default using a tuned XGBoost model. The primary goal of this project is to provide an accessible and practical tool for evaluating borrower risk, helping users make informed credit decisions based on data-driven insights. By combining machine learning, data analysis, and an interactive user interface, the application makes credit risk prediction easier to understand and use for both individuals and financial decision-makers.

At the heart of the project is a machine learning pipeline that processes financial and applicant-related data to estimate whether a borrower is likely to default on a loan. The XGBoost model is trained and tuned to improve predictive performance, helping it capture complex patterns in credit data more effectively than simpler models. This makes the project useful for real-world credit assessment scenarios, where predictive accuracy and interpretability are both important.

The application is built with Streamlit, allowing users to interact with the model through a clean and user-friendly web dashboard. It supports two main modes of use: single applicant evaluation and batch prediction. In the single evaluation mode, a user can input borrower information such as income, loan amount, debt ratio, credit history, and other relevant financial variables. The app then processes the inputs and returns a prediction indicating whether the applicant is at low or high risk of default.

In addition to single-case predictions, the project also enables CSV upload for batch processing. This feature allows users to upload a dataset with multiple loan applications and receive predictions for each entry in one go. The results are displayed in a structured format and can be downloaded for further analysis or reporting. This makes the application especially useful for institutions or teams that need to assess large numbers of applicants efficiently.

To ensure the model is both reliable and understandable, the project includes model evaluation metrics such as accuracy, precision, recall, F1-score, and classification reports. These metrics help users assess the effectiveness of the model and understand its performance across different classes. This gives the project a more complete and professional data science workflow, beyond simple prediction output.

The repository also reflects a complete end-to-end machine learning workflow: data preprocessing, exploratory analysis, feature engineering, model training, validation, and deployment into a usable web app. This makes the project a strong example of how machine learning can be applied to real business problems in a way that is both practical and easy to demonstrate. It showcases not only model-building skills but also the ability to turn a machine learning concept into an interactive application.

This project is highly relevant in the financial domain, where credit decisions have a major impact on lending operations and risk management. It demonstrates how predictive analytics can support faster and more consistent decision-making while reducing manual effort. The app is a useful example of a fintech-style solution, combining business value with technical execution.

Built using Python, Streamlit, XGBoost, pandas, scikit-learn, and other supporting libraries, this project highlights a strong combination of data science, analytics, and software engineering. It is an effective demonstration of creating a real-world machine learning application that is both functional and user-friendly.
